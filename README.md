# Sandstorm Strike

Оригинальная мобильная тактическая FPS (не клон Standoff 2 — своя карта, свои текстуры, свой код).

## Сборка и скачивание
APK собирается автоматически через GitHub Actions (`.github/workflows/build.yml`).
Готовый файл: `app/build/outputs/apk/debug/app-debug.apk`.
Каждая сборка автоматически публикуется в **GitHub Releases** — оттуда скачивать быстрее.

## LAN
- До 10 игроков, один хост.
- Хост нажимает «Создать комнату» и видит свой IP (например `192.168.1.10:27315`).
- Остальные нажимают «Войти по IP» и вводят этот адрес.
- Все устройства в одной Wi-Fi сети. Режим: deathmatch с респавном.
- Обмен по TCP, хост считает всё, клиенты отправляют ввод.

## Что есть
- **Карта «Дюна»** (24×24): две точки закладки A/B, балконы с перилами и пандусами, покрытие, несколько маршрутов.
- **Режимы**: офлайн (ELO копится офлайн и синхронизируется при подключении), онлайн (ELO сразу), LAN (до 10 игроков, один хост).
- **Раунды 5v5**: закладка бомбы, взрыв, обезвреживание, чередование команд по раундам, таймеры, счёт.
- **Боты**: 3 уровня сложности (лёгкие / средние+ / хард), патрулирование, поиск цели, стрельба с учётом распределения и укрытий.
- **Оружие**: пистолет, SMG, винтовка, дробовик, снайперская — свои характеристики, перезарядка, разброс, отдача.
- **Скины**: 5 вариантов на каждое оружие.
- **8 эффектов убийства**: чёрная дыра, взрыв, кровь, молния, огненный шторм, ледяные осколки, неоновый взрыв,-void.
- **ELO и кланы**: таблица лидеров, накопление ELO офлайн, синхронизация, названия кланов.
- **Настройки**: чувствительность, 5 стилей прицела, цвет и размер прицела, баннихоп (×1.2 / ×1.3 / ×1.5), инверт Y, качество графики, сложность ботов, свой фотофон неба.
- **Управление**: виртуальный джойстик слева, плавный обзор справа, кнопки огня/прыжка/приседа/перезарядки/закладки/смены оружия.

## Управление (клавиатура)
WASD — движение, стрелки — поворот, Space — баннихоп, Ctrl/Shift — присесть,
R — перезарядка, E — закладка/обезвреживание.

## Техническое
Чистый Java + SurfaceView, программный raycasting-рендер (стены с текстурами, пол/потолок, спрайты, частицы).
Минимальная версия Android — 5.0 (API 21). Разрешение рендера 240×135 / 360×203 / 480×270.
